1. 시작하기

본 플랫폼은 한국형 V2X 자율주행 의사결정 평가용 데모입니다. NVIDIA Alpamayo 1.5(10B VLA)와 Cosmos-Reason2 8B(VLM)를 기반으로, V2X 메시지가 자율주행 모델의 의사결정에 미치는 영향을 정량 평가합니다.

권장 평가 흐름

  1. ① 시나리오 단건 평가: 가장 먼저 모델을 적재(~1분)하고 V2X 효과를 정량 확인
  2. ② 시연 자동 실행: 사전 렌더링된 20 시나리오 시연 영상 갤러리
  3. ③ 실시간 인터랙티브: V2X preset을 즉시 전환하며 BEV 변화 관찰
  4. ④ VQA: 주행 장면에 자유 질의 응답
  5. ⑤ 카메라 입력 개수: 1/2/4cam 구성별 강건성 비교
  6. ⑥ Closed-Loop: NRE 폐루프 시뮬레이션 결과 재생

사전 준비

최초 진입 시 ① 탭에서 모델 적재 버튼을 누르고 약 1분 대기. 적재 후엔 모든 탭이 즉시 응답합니다.

2. ① 시나리오 단건 평가

단일 시나리오에 대해 V2X 메시지 / baseline(V2X 미수신) / 반사실(counterfactual) 3조건의 궤적 예측을 비교, ADE / FDE / 측방 편차 / 방위 오차를 BEV 위에 즉시 정량 비교.

사용 절차

  1. 처음 진입 시 "모델 적재" 클릭 → 약 1분 대기 (상태 자동 갱신)
  2. 시나리오 드롭다운에서 평가 대상 선택 (예: [00] 근거리 좌회전 · 11.2m)
  3. V2X 메시지 입력창에 메시지 타이핑 (예: Turn left in 5m), 또는 비워서 시나리오 기본값 사용
  4. baseline / 반사실 체크박스 그대로 두고 "▶ 3조건 단일 추론 실행" 클릭
  5. 약 30~60초 후 BEV 이미지 3장 + 메트릭 테이블 출력

결과 해석

  • ADE (Average Displacement Error): 예측과 GT 궤적의 평균 거리. 작을수록 양호.
  • FDE (Final Displacement Error): 마지막 시점의 거리. ADE보다 큰 경향.
  • Max lateral deviation: 측방 최대 편차 — 차선 이탈 위험 지표.
  • Heading error: 방위 오차 — 진로 방향 정확도.
  • 해석 기준: V2X 조건 ADE ≤ baseline ADE면 V2X 메시지의 의사결정 개선 효과 확인.

자주 묻는 질문

Q. "모델이 적재되지 않았습니다" 경고가 보입니다.
A. 모델 적재 버튼을 누르고 상태가 ready가 될 때까지 (~1분) 기다린 후 다시 실행하세요.
Q. 반사실(counterfactual)은 무엇을 의미하나요?
A. 같은 시나리오에 정반대 V2X 메시지를 주입했을 때의 모델 응답입니다. V2X 메시지가 모델 의사결정에 실제 영향을 주는지의 sanity check.

3. ② 시연 자동 실행

사전 렌더링된 20개 시나리오의 시연 영상 갤러리. 각 영상은 카메라 + V2X 배너 + AI reasoning 자막 + 예측 BEV가 7.5초 합성된 timeline.

사용 절차

  1. 관심 시나리오 영상의 ▶ 버튼 클릭 → 7.5초 재생 (loop)
  2. 영상을 일시정지/탐색하려면 video controls 사용
  3. 다른 영상도 동시에 재생 가능

결과 해석

  • 2 fps × 15 프레임 = 7.5초. 실시간이 아닌 슬로우 모션 시각화.
  • 좌상단 V2X 배너 / 좌하단 AI 추론 자막 / 우하단 메트릭 동시 비교.
  • 시나리오 라벨은 거리/방향 카테고리로 표기 (예: [15] 중거리 좌회전 · 17.8m).

자주 묻는 질문

Q. 영상이 짧아 보입니다.
A. 의도된 7.5초 슬로우 모션입니다. 시각적 임팩트를 위해 loop 자동 재생.
Q. 영상이 로드되지 않습니다.
A. 페이지 새로고침 후 재시도. 그래도 안 되면 운영자에 문의.

4. ③ 실시간 인터랙티브

시나리오를 선택하면 카메라 영상과 BEV 예측이 즉시 표출되고, V2X preset 버튼으로 메시지를 바꿔가며 BEV 변화를 실시간 비교 가능.

사용 절차

  1. 시나리오 드롭다운에서 평가 대상 선택
  2. 카메라 영상 + 기본 BEV 자동 표출
  3. V2X preset 버튼 (예: ↰ left 30m) 클릭 → BEV 즉시 갱신
  4. 여러 preset을 순서대로 클릭하며 BEV 차이 관찰

결과 해석

  • preset 전환 시 BEV 궤적이 메시지 거리/방향에 정합하면 V2X 효과 시각 확인.
  • preset 간 차이가 없으면 모델이 V2X에 둔감하거나 시나리오가 V2X 무관.

자주 묻는 질문

Q. preset 클릭해도 BEV가 변하지 않습니다.
A. 일부 시나리오는 V2X 효과가 미미할 수 있습니다. ① 탭에서 정량 메트릭으로 추가 확인 권장.

5. ④ VQA — 시각 질의응답 (라이브)

Alpamayo 1.5의 VLM 부분(Cosmos-Reason2 8B)에 주행 장면에 대해 자유 질문을 던지면 30~40초 후 응답 표출. Dual-mode 모델 — 질문 유형에 따라 자연어 / bbox 좌표 응답이 자동 결정됨.

사용 절차

  1. 시나리오 드롭다운에서 장면 선택 → 카메라 영상 표출
  2. 가이드 표를 참고해 질문 입력 (자연어 응답이 보장된 질문 권장)
  3. "▶ 질문" 클릭 → 30~40초 대기 → 응답 표출

결과 해석

  • 자연어 응답: "맑은 날씨, 평탄한 아스팔트…" 형태. 날씨/조명/도로 속성 질문이 트리거.
  • bbox 좌표: [0.303, 0.221, 0.589, 0.674] 형태. 장면/객체/사건 질문이 트리거 (객체 감지 모드).
  • 모드는 모델 내부에서 결정. 프롬프트로 강제 불가.

자주 묻는 질문

Q. Describe the scene.에 좌표만 나옵니다.
A. 정상 동작. 장면/객체 질문은 객체 감지 모드를 트리거. 자연어 응답을 원하면 Describe the road and weather. 같은 속성 질문 사용.
Q. 응답이 너무 느립니다.
A. VLM 추론은 1회 ~30초가 정상. 캐시되지 않은 라이브 추론입니다.

6. ⑤ 카메라 입력 개수 평가

동일 시나리오에 카메라 입력을 1/2/4개 구성으로 변경해 추론, 센서 일부 고장 / 비용 절감 / 강건성 평가.

사용 절차

  1. 시나리오 드롭다운에서 평가 대상 선택
  2. 1cam / 2cam / 4cam 각 구성의 BEV 이미지 + Chain-of-Thought + 메트릭 표 자동 표출

결과 해석

  • cam 수가 늘수록 ADE/FDE 감소면 다중 카메라 효과 정상.
  • 1cam에서 ADE > 5m 등 극단 수치면 단일 센서 한계 시연.
  • 2cam vs 4cam 차이가 작으면 후방/측면 카메라 보조 효과 제한적.

자주 묻는 질문

Q. CoT 텍스트가 동일합니다.
A. 시나리오가 단순하면 추론 근거가 같을 수 있음. 다른 시나리오로 비교 권장.

7. ⑥ NRE Closed-Loop 시뮬레이션 분석

NVIDIA Neural Reconstruction Engine으로 6대 카메라를 신경망 재합성하며 매 step Alpamayo↔물리↔컨트롤러가 RPC로 사이클을 도는 closed-loop 시뮬레이션 결과 재생. 시연 자리에서는 사전 렌더링된 영상 + trace + 메트릭 + PDF.

사용 절차

  1. rollout 드롭다운에서 분석 대상 선택
  2. 최상단에 NRE 합성 영상 (front_wide 120fov + V2X/메트릭/속도 오버레이) 자동 재생
  3. 아래로 스크롤 → 시뮬 시간/속도/측방 가속 plot + step-by-step trace slider
  4. "📷 frames 추출" / "📄 PDF 생성" 버튼으로 보조 자료 생성 (선택)

결과 해석

  • NRE 영상은 매 step 신경망 재합성된 실제 시뮬 데이터.
  • 속도/측방 가속 plot이 안정적이면 controller가 정상 작동.
  • jerk가 큰 시점이 있으면 급제동/급조작 → 사고 회피 또는 모델 불안정 흔적.

자주 묻는 질문

Q. rollout 선택 시 "영상 미생성" 안내가 나옵니다.
A. 해당 rollout의 NRE frame 데이터가 누락. 운영자 호출.
Q. 폐루프 시뮬을 새로 돌릴 수 있나요?
A. ① 탭의 "Closed-Loop 시뮬레이션 실행" 버튼으로 가능하나 단일 scene당 60~80분 소요. 시연 자리에서는 사전 렌더 결과 재생을 권장.

8. 트러블슈팅

평가위원이 자가 해결 가능한 일반적 상황.

"모델이 아직 적재되지 않았습니다." 경고
① 탭의 모델 적재 버튼 클릭 → 상태가 ready가 될 때까지 (~1분) 대기. 한 세션 내 1회만 필요.
④ VQA 응답이 [0.3, 0.5, ...] 좌표만 나옴
Dual-mode 모델의 정상 동작. 객체 감지 모드가 트리거된 것입니다. 자연어 응답이 필요하면 가이드 표의 "자연어 응답 보장 질문"을 참고.
⑥ rollout 선택 시 "영상 미생성" 안내
사전 렌더링이 누락된 rollout. 다른 rollout 선택 또는 운영자 호출.
② 카메라 영상이 첫 프레임만 길게 멈춤
시뮬 데이터가 짧을 때 정상 (Tab ②는 2 fps 슬로우 모션 7.5초). 다른 시나리오 선택.
탭을 클릭해도 콘텐츠가 안 뜸
브라우저 새로고침 (F5). 그래도 안 되면 운영자 호출.
한글이 □□□로 깨져 보임
브라우저에 한글 폰트가 없는 경우. 시스템 한글 폰트(Noto Sans KR / 맑은 고딕 등) 설치 후 재접속.
